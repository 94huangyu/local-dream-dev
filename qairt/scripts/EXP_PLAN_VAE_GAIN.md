# EXP_PLAN_VAE_GAIN —— VAE 导出缺陷的性质：全局增益 还是 结构性锐化？

定稿时间：**2026-08-21**（执行前定稿，**判据不得事后修改**）
归属主线：A（排查）· 阶段 0（导出保真度）· #71 逐层定位的**前置设计门**

---

## 一、背景（①实测）

`../docs/reviews/REVIEW_VAE_EXPORT_2026-08-19.md` 把 VAE 导出缺陷描述为
**"高频能量高出 +30.5%，细节被推成高对比硬边"**（即锐化），并据此把 #71 的探针设为
"高频能量从哪一层开始发散"。该文档 §5 第 2 条自己标注：**这把尺子未经已知样本验证。**

2026-08-21 在已有 PNG 上的只读复核（①实测）：

| 量 | 官方 PyTorch | 我们的 ONNX |
|---|---|---|
| 像素 std | 51.293 | **65.729** |
| 被钳到 0 / 255 的像素 | 0.016% / 0.000% | **7.953% / 2.225%** |
| 梯度能量 | 2.8917 | 3.7734（**+30.5%**） |
| 梯度能量（全局 mean/std 对齐后） | 2.8917 | **2.9447（+1.8%）** |

**std 之比 1.2815 与梯度能量之比 1.305 几乎相等** —— 梯度随对比度线性缩放
⇒ ③**该缺陷可能是"整体增益 + 钳位"，而不是"锐化"。**

⚠️ 上述是在**已钳位的 8-bit PNG** 上算的，钳位本身压低梯度 ⇒ "+1.8%" 是下界，**不足以定论**。

## 二、这个实验为什么值得做（推进主线的理由）

#71 逐层定位已失败一次，正准备重做，**重做时"测什么量"是核心设计**：

- 若是**锐化** ⇒ 探针测高频/相对 L2（现方案）
- 若是**增益** ⇒ 探针应测**逐层输出 std 之比**（尺度不变、单标量、形状错位立即暴露）

**用错探针 = 把上一次的失败再做一遍。** 本实验是 #71 的设计门，非可选。

## 三、实现目标

在**钳位前的 float 输出**上判定：ONNX 臂与官方臂的差异，能否被一个**全局仿射**（增益+偏置）解释。

## 四、实现路径

1. 输入 `D:\ZImage_Work\p0_experiments\fp32_steps\lat_8.raw`，**运行时断言 std ≈ 1.0996**（身份门，不由文件名推断）
2. `vae_in = lat/0.3611 + 0.1159`，与 `vae_ab.py` 逐字相同
3. 臂 A：官方 PyTorch `AutoencoderKL.decode` → `px_A`（fp32，钳位前）
4. 臂 B：我们的 ONNX + ORT CPU → `px_B`（fp32，钳位前）
5. **两臂 float 输出一律落盘**（`scratch_runs/vae_gain_pxA.npy` / `pxB.npy`）——
   吸取 15.21.6 教训：中间产物默认落盘
6. 校正：`px_B_corr = (px_B − mean(px_B))/std(px_B) × std(px_A) + mean(px_A)`
7. 两臂各过 `to_img`（与 `vae_ab.py` 逐字相同的 clip+量化），算平均 |像素差|

## 五、🔒 判据（事前锁定，不得事后修改）

**主判据**：校正后 ONNX 臂 vs 官方臂的**平均 |像素差|**

| 结果 | 判定 | 后续动作 |
|---|---|---|
| **< 3.0** | 缺陷是**纯全局增益** | #71 探针改为「逐层输出 std 之比」，追增益累积起点 |
| **> 8.0** | 增益**不是**主因 | 本条线到此为止，回到原方案（高频发散定位） |
| **3.0 ~ 8.0** | 两者兼有 | #71 需同时记录 std 比与形状归一化后的残差 |

**V 门（有效性门，先过）**：未校正时的平均 |像素差| 必须复现 **13.326 ± 0.20**。
不通过 ⇒ 输入或环境不对，**本实验作废，不得下任何结论**。

## 六、G-check：判据操作化的已知样本验证（约束 8，先跑，不过则实验作废）

本项目曾一天内三次把判据的操作化写错。本判据涉及"跨对象可比性"，必须先验证操作化本身成立：

| 控制组 | 构造（已知答案） | 必须满足 |
|---|---|---|
| **C1** | `1.2815 × px_A + 0.05`，真值 = **纯增益** | 判据结果 **< 3.0** |
| **C2** | `3×3 均值模糊(px_A)`，真值 = **结构性差异** | 判据结果 **> 3.0**，且显著大于 C1 |

C1 不过 ⇒ 校正+度量无法识别纯增益；C2 不过 ⇒ 该判据对任何输入都返回小值，无分辨力。
**任一不过，本实验结论作废。**

## 七、附带记录（**不是判据**，仅供 #71 设计参考）

- 两臂 float 的 mean / std / 增益比 `k = std_B/std_A`
- 最小二乘仿射拟合 `px_B ≈ a·px_A + b`，报 `a`、`b`、残差相对 L2
- **按约束 7**：凡报相对 L2，同时报"前 1% 元素占 `‖a‖²` 的比例"；
  若 > 50%，另报主体口径（`|a| ≤ p99`）
- 两臂在 `to_img` 前超出 `[−1, 1]` 的元素比例（钳位损失的真实规模）

## 八、失败时如何归因

- **V 门不过** ⇒ 执行方法错误（输入/环境），不是方向错误，修正后重跑
- **G-check 不过** ⇒ 判据操作化错误，重新设计判据，**不得**改判据阈值去迁就结果
- **V 门与 G-check 都过、主判据落在 >8.0** ⇒ **方向错误**，我的增益假设被证否，如实记录并回到原方案

## 九、【2026-08-21 执行中】🔴 第一版判据 G-check 未过 —— 判据重设（原文保留，约束 2）

**实测**：

| 门 | 结果 |
|---|---|
| 身份门（latents std=1.0996） | ✅ |
| V 门（未校正像素差 13.326） | ✅ **精确复现文档值** |
| C1 纯增益构造 → 要求 <3.0 | ✅ **0.000**（校正能完整吃掉纯增益） |
| C2 3×3 模糊构造 → 要求 >3.0 | ❌ **1.162** |

**失败原因（不是方向错，是操作化错）**：§五的阈值 3.0/8.0 是照着未校正值 13.326 拍的**绝对像素数**。
但 1024² 照片绝大部分是平滑区，一次**肉眼可见的结构改变**（3×3 模糊）只产生 1.162 的平均像素差
⇒ 该判据会把"模糊"也判成"纯增益"，**对结构性差异无分辨力**。

⚠️ 此时**尚未计算真实那一对的校正后像素差** ⇒ 重设判据不受结果污染。

### 九·1 重设后的判据（🔒 二次锁定，仍不得事后修改）

**改绝对量为尺度无关量**，并把**竞争假设本身**加入控制组：

- **EF（增益解释率）** `= 1 − d_corr / d_raw` —— 全局仿射校正吃掉了多少比例的可见差异
- **RS（残差倍数）** `= d_corr / d_corr(C2)` —— 剩余差异相当于几次"3×3 模糊"那么大

| 结果 | 判定 | 后续动作 |
|---|---|---|
| **EF ≥ 0.90 且 RS ≤ 1.0** | **增益主导** | #71 探针改为「逐层输出 std 之比」 |
| **EF ≤ 0.50** | **增益非主因** | 假设被证否，回原方案（高频发散定位） |
| 其余 | **两者兼有** | #71 两个量都记 |

### 九·2 重设后判据的 G-check（三个控制组，全过才继续）

| 控制组 | 构造（已知答案） | 必须满足 |
|---|---|---|
| **C1** | `1.2815·px_A + 0.05` = 纯增益 | **EF ≥ 0.90** |
| **C2** | `3×3 均值模糊(px_A)` = 结构性差异 | **EF ≤ 0.50** |
| **C3** | `px_A + 0.5·(px_A − 模糊)` = **锐化**（← 竞争假设本身） | **EF ≤ 0.50** |

**C3 是本次新增的关键控制组**：它构造的正是文档主张的那个缺陷（锐化）。
若判据连"真锐化"都判成增益，则它无法区分两个假设，结论无意义。

## 十、【2026-08-21】主判据结果 = **两者兼有**，追加残差性质判别（🔒 三次锁定，先锁后看）

### 十·1 已得结果（①实测）

| 门/量 | 结果 |
|---|---|
| V 门 | ✅ 13.326，精确复现 |
| G-check C1 纯增益 / C2 模糊 / C3 **锐化** | ✅ EF = 1.000 / −0.016 / −0.033 |
| **主判据** | **EF = 0.7643，RS = 2.702 ⇒ 🔶 两者兼有** |
| 全局仿射 | `px_B ≈ 1.3324·px_A + 0.00222`，**R² = 0.9903**，残差相对 L2 **9.86%**（前 1% 占能量 6.10% ⇒ 全量口径合法） |
| 逐通道增益 | 1.3432 / 1.3109 / 1.3234（**近似各向同性**） |
| 钳位损失 | 官方 0.006% ｜ **ONNX 9.882%**（低端 7.657% + 高端 2.225%） |

⇒ ②**"+30.5% 高频能量"这个量基本就是增益本身**（增益 1.3389 vs 高频比 1.305）——原判据在量对比度。
⇒ ②**但确实存在一个非增益的残差**，量级约 2.7 倍 3×3 模糊，**不得当成噪声忽略**。

### 十·2 追加实验：残差是「逐点非线性」还是「空间结构」？

**为什么必须分**：这决定 #71 的探针形态。
- 逐点（pointwise）⇒ 缺陷仍是"每个元素被同一条曲线映射"，**逐层 std 之比 + 传递曲线**即可定位
- 空间结构 ⇒ 必须用形状敏感的量，逐层 std 比不够

**方法**：用 `px_A` 的 64 个分位桶拟合一条**逐点单调映射** `f`（桶内 `px_B` 均值），
令 `px_B_pw = f(px_A)`，走与主判据相同的 `to_img` + 平均|像素差| 流程。

**度量**：`EF_pw = 1 − d(f(px_A), px_B) / d_raw`

| 结果 | 判定 | 后续动作 |
|---|---|---|
| **EF_pw ≥ 0.90** | 缺陷**纯逐点**，无空间结构 | #71 用「逐层 std 之比 + 逐点传递曲线」 |
| **EF_pw ≤ 0.50** | 存在实质空间结构 | #71 必须改用形状敏感量 |
| 其余 | 兼有 | #71 两者都记 |

**G-check（同三组，全过才采信）**：C1 纯增益 `EF_pw ≥ 0.90`；
C2 模糊 `EF_pw ≤ 0.50`；C3 锐化 `EF_pw ≤ 0.50`
（逐点映射**原理上无法**修复模糊/锐化，若它却给出高 EF_pw，说明该操作化有漏洞）。

**附带记录（非判据）**：残差幅值与 `px_A` 局部梯度幅值的相关系数
—— 若强正相关 ⇒ 残差集中在边缘，指向卷积/Resize；若无关 ⇒ 指向归一化。

### 十·3 §十 结果（①实测）与实验结论

| 门/量 | 结果 |
|---|---|
| G-check C1/C2/C3 | ✅ EF_pw = 1.000 / −0.051 / −0.079 |
| **主判据 EF_pw** | **0.7159 ⇒ 🔶 兼有** |
| 逐点残差相对 L2 | **9.8163%**（线性仿射残差 **9.8636%**） |
| 残差幅值 vs 局部梯度幅值 相关系数 | **+0.5808** |
| 传递曲线局部斜率（8 个采样点） | 1.3784 / 1.2887 / 1.3308 / 1.4696 / 1.1307 / 1.2279 / 1.3426 / 1.4040 |

⇒ ②**残差不是逐点非线性**：64 段自由度的单调映射只把残差从 9.8636% 降到 9.8163%（0.05 pp）。
⇒ ②**残差是空间结构性的，且集中在边缘/高活动区**（r = +0.58）。

### 十·4 🔒 本实验的最终结论（三条，全部 ②级）

1. **VAE 导出差异 = 一个近各向同性的全局增益 ×1.3324（R² = 0.9903）＋ 一个 9.86% 的空间结构残差。**
2. **原"+30.5% 高频能量"这把尺子量到的基本就是那个增益**（增益 1.3389 vs 高频比 1.305）
   ⇒ 文档中"细节被推成硬边（锐化）"的表述**证据不足**，"高对比"部分才是被证据支持的。
3. **增益导致 9.882% 的像素被钳死**（官方 0.006%）⇒ 死黑/溢白很可能是"蜡质发硬"观感的直接来源。

### 十·5 对 #71 的设计要求（本实验的交付物）

#71 逐层探针**必须同时记录两个量**，且两者的相对权重已知（增益占可见差异 76.4%）：

| 量 | 追什么 | 预期可分辨的两种形态 |
|---|---|---|
| **逐层输出 std 之比**（ONNX/PyTorch） | 1.3324 的增益在哪累积 | **均匀累积**：30 个 GroupNorm 每个约 `1.3324^(1/30) = 1.0095`（+0.95%/层）<br>**单点跳变**：某一层直接跳到 1.33 |
| **形状敏感量**（残差 vs 局部梯度相关） | 9.86% 的结构残差在哪引入 | 若与 Resize/Conv 同层出现 ⇒ 指向重采样/卷积实现 |

⇒ **原方案"高频能量从哪层发散"被取代**：该量已被证明主要在反映增益，单独用会重复本次的错误。
