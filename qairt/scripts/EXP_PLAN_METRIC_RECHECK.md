# EXP_PLAN_METRIC_RECHECK —— #84：三把尺子的"反相关"是不是坏 VAE 的钳位假象？

定稿时间：**2026-08-21**（执行前定稿，**判据不得事后修改**）
前置：#80 已证明此前所有成图都经过一个把 2.5%~9.9% 像素压成死黑/溢白的 VAE

---

## 〇、🔴 先收窄范围：**有一把尺子不需要复查**

#69 主张三把尺子全部反相关：`E_all` ／ 像素差 ／ PSNR。

但 **`E_all` 是 step-0 噪声预测相对 FP32 的相对 L2，算在 latents 上，完全不经过 VAE**
⇒ ②**VAE 的喂法 bug 在原理上不可能影响它。**

⇒ ②**"E_all 43.41% → 44.80%（更差），而图从认不出任何物体变成清晰的猫"这一条独立成立，
无需复查。** #69 里最反直觉的那一半是真的。

⇒ **本实验的范围只剩两把经过 VAE 的尺子：像素差 与 PSNR。**

（这一条不花成本就把工作量砍掉一半——先想清楚"这个量到底经过哪些环节"，再决定要不要重跑。）

## 一、实现目标

判定：**"四段(清晰猫) 的像素差/PSNR 比 三段(马赛克) 更差"** 这个反相关结论，
在修好 VAE 喂法之后是否还成立。

## 二、实现路径（纯宿主，不占设备）

1. **重建两次在环运行的末步 latents**（无需重跑设备）：
   末步 `dt = 0 − σ₇` ⇒ `final = lat_s7 − dt·noise_s7 = lat_s7 + σ₇·noise_s7`
   输入：`htp_inloop_{ctl3seg,perrow4seg}/s7/{latents,latents_dev}.raw`
2. **FP32 参考**：用**同一份初始噪声与 caption**（已核 md5 逐位相同）重跑 FP32 全流程，
   喂法用修正后的 `lat + shift·s`（`FP32_TAG=inloopref_vaefix`）
3. 三份末步 latents 各用**旧喂法**与**新喂法**解码，算像素差 / PSNR / 钳位比例

## 三、🔒 判据（事前锁定）

### V 门（先过，不过则作废）

| 门 | 要求 | 抓什么 |
|---|---|---|
| **V1** | 两次在环运行的 `s0/latents.raw` 与 `const/caption.raw` md5 **逐位相同** | 单变量前提。**已过**（`99ff38fd…` / `2ae471cc…`） |
| **V2** | 用**旧喂法**重解码，必须复现历史记录：三段像素差 **41.37**、四段 **44.52**（±0.5） | **这是"末步 latents 重建是否正确"的唯一验证**。不过 ⇒ 重建公式或数据不对，实验作废 |

⚠️ V2 若因 FP32 参考不同源而系统性偏移，则**只比较两臂的相对次序**，
并在报告中显式声明"不与历史绝对值比较"。

### 主判据

令 `d3` = 三段(马赛克) 对 FP32 的平均 |像素差|，`d4` = 四段(清晰猫) 的。

| 结果（**新喂法**下） | 判定 | 后续动作 |
|---|---|---|
| **d4 < d3** | 🔴 **反相关是钳位假象** | #69/#70 必须重新表述；§2.3「暂停标量决策」解除；**P1 三层指标面板的必要性下调** |
| **d4 > d3 且差距 ≥ 旧喂法下的一半** | ✅ **反相关成立** | #69/#70 维持原样，#84 关闭；三层指标面板仍需要 |
| 其余（差距显著缩小但未翻转） | 🔶 **部分是钳位假象** | 两条结论都要加限定，不得原样引用 |

### 附带记录（非判据）

- 三张图各自被钳到 0 / 255 的像素比例（新旧喂法各一份）
- PSNR 的次序是否与像素差一致（两把尺子是否同步翻转）

## 四、失败归因
