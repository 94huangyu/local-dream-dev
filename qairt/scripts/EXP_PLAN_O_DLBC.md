# EXP_PLAN_O_DLBC —— #94：`O`（图优化级别）与 `dlbc` 对**算子级精度**的影响

定稿时间：**2026-08-22**（执行前定稿，**判据不得事后修改**）
试验台：P0-B 的单算子精确重放（baseline 配置）

---

## 一、为什么值得做

#93 已实测：这两个选项经 `.bin` 路径**真的生效**（md5 与体积都变），而**精度效果从未测过**：

- **`O`**：#19 测过"O=3 精度无改善（Δcos −0.0005）"，但那是**端到端**口径；
  算子级从未测过，而算子级信噪比高得多
- **`dlbc`**：**精度效果完全未测**。#57 只排除了它对 **PD 容量**的影响，
  **不是精度** —— 两者不是同一个问题，不得互相引用

## 二、🔴 单变量的关键处理

实测发现：**"带 `--config_file`" 与 "不带" 的产物本身就不同**
（`9ccc464d…` vs `e273d197…`），所以**不能拿历史的 `E = 1.5544%` 当对照基准**。

⇒ **对照臂 CTRL = 带 config、但选项无效果**（`vtcm_mb: 8` —— #93 已实测 2/4/8 产物相同，即无效果）。
所有比较都对 CTRL 做。

| 臂 | `graphs[0]` 内容 |
|---|---|
| **CTRL** | `{graph_names:[fc99_fp32], vtcm_mb:8}` |
| **O1** | CTRL + `O:1` |
| **O3** | CTRL + `O:3` |
| **DLBC** | CTRL + `dlbc:1` |

## 三、🔒 判据（事前锁定）

### V 门

| 门 | 要求 |
|---|---|
| **V0** | 四臂 context md5：**O1 / O3 / DLBC 必须各自与 CTRL 不同**（#93 已预验证）。相同 ⇒ 该臂无效，不参与判定 |
| **V2** | 每臂设备输出字节数 = **63,406,080**（约束 3） |
| **V3** | 输入 md5 = `eb9b583a0b41f8f37bfb69cc8077a9b5` |

### 主判据

令 `E_CTRL` = 对照臂实测值（**不是**历史的 1.5544%）：

| 结果 | 判定 | 后续 |
|---|---|---|
| 某臂 **E ≤ 0.90 × E_CTRL** | 🔴 **该选项有算子级精度收益** | 评估端到端（体积/速度/PD 红线），并复核 #19 的端到端结论 |
| 某臂 **E ≥ 1.10 × E_CTRL** | ⚠️ **该选项有害** | 记录，确保产品配置里没开 |
| 全部落在 0.90~1.10 之间 | ✅ **无精度影响** | #94 关闭；`O`/`dlbc` 从候选里划掉 |

### 附带记录（非判据）

- `E_CTRL` 与历史 `1.5544%`（无 config）之比 ⇒ **"仅仅加上 config 文件"本身是否影响精度**
  （若影响显著，是一条独立的新发现）

## 四、失败归因

- V0 某臂不过 ⇒ 该选项对本图无效果，**不算方向失败**，该臂退出判定
- V2/V3 不过 ⇒ 装置问题
- 三门全过 ⇒ 无论落哪个区间都是有效结论
