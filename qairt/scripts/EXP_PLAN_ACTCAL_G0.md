## 二、候选与现状

`--act_quantizer_calibration` 官方取值：**min-max（默认）/ sqnr / entropy / mse / percentile**。
当前部署 = **min-max**；percentile = 已实测灾难 ⇒ **本门只评 sqnr / entropy / mse**。

## 五、🔒 判据（事前锁定）

对每个方法 m 与张量 T，报 **纯表示误差**（Q/DQ 后 vs 原 fp32），两个口径都报：
`E_full(m,T)` 与 `E_bulk(m,T)`（`|a| ≤ p99`），并报前 1% 能量占比（约束 7）。

**参照**：当前 min-max 在 `unified` 上的已知值 —— 全量 **0.1884%** / 主体 **4.5227%**
（CLAUDE.md 约束 4·补 所载）。⚠️ 本门须**自行复算**该值，与记载吻合才继续（V1 门）。

| 条件 | 判定 |
|---|---|
| `E_full(m, unified) > 7.87%`（当时的端到端实测误差） | ❌ **直接否决，不许上机**（照搬 percentile 那次的否决条件） |
| 未被否决 且 `E_bulk(m,unified) < 0.5 × E_bulk(min-max,unified)` 且 `E_full(m) ≤ 2 × E_full(min-max)` | 🟢 **值得上机**：主体大幅改善且未牺牲动态范围 |
| 未被否决 但不满足上一行 | 🟡 **不值得单独立项** |

🔴 **本门只能否决，不能证明有收益**（#52：表示误差不是 HTP 误差的预测量）。
⇒ 🟢 的措辞只能是"值得上机验证"，**不得写成"会改善"**。
