# EXP_PLAN_ATTENTION —— 注意力/Softmax 是不是 HTP 误差的主要来源？（台账 #11）

定稿时间：2026-08-15（执行前定稿，判据不得事后修改）
主线归属：A → "如何解决 HTP 的数值问题"

## 0. 为什么是它，以及为什么它被漏了

`scaled_dot_product_attention_18`（注意力输出）实测误差
**127.25%（全量）/ 139.94%（主体）——全部 29 个探针张量中最高**。

**但它从未被查过。** 原因是我在第二轮探针里主动跳过了两个 2 GB 的注意力矩阵
（`val_2591` 打分、`val_2592` softmax 输出），随后被一个**后来被证伪**的
"RmsNorm 是放大点"分析带走，再没回来。台账 #11 从建表起就是"未查"。

同时官方文档明确：Softmax 在 16-bit 激活下 in/out 只支持 UFxp16/SFxp16，
而本模型的注意力矩阵是 **4128 x 4128**，属超长序列的定点归一化，**精度敏感**。

## 1. 假设

**H-attn**：HTP 的注意力段（MatMul 打分 → Softmax → MatMul 加权）
是误差的主要引入点；其上游 Q/K/V 误差显著低于其输出误差。

零假设：注意力段的输出误差与其输入误差同量级 ⇒ 它只是传递误差，不是引入点。

## 2. 实现路径

从**已有的**第二轮设备/CPU 数据出发，只需补测 2 个张量：
`val_2591`（QK^T 打分，2.04 GB）、`val_2592`（Softmax 输出，2.04 GB）。

依赖链（已由 `trace_dag.py` 读出）：
```
transpose_72/73/74 (Q/K/V)
  -> val_2587 / val_2590  (缩放/转置)
  -> val_2591  = MatMul(Q, K^T)        <- 补测
  -> val_2592  = Softmax(val_2591)     <- 补测
  -> scaled_dot_product_attention_18 = MatMul(val_2592, V)   <- 已有
```

设备侧：`qnn-net-run --dlc_path part1b.dlc --set_output_tensors ...val_2591,val_2592`
宿主侧：`snpe_runner.py` 取同名张量。约 4 GB 落盘 + 4 GB 传输。

## 3. 判据（事后不得修改）

**度量口径按约束 7 执行**：每个张量同时报告
① 主体相对 L2（|a| <= p99）② 主体余弦 ③ 前 1% 元素占 ||a||^2 的比例。
**余弦 < 0.3 的张量退出定量比较**，只标记"已毁"。

**判据 0（有效性）**：两侧元素数一致；`scaled_dot_product_attention_18`
必须与已有第二轮数据逐位相同（证明两次运行等价）。

**判据 1（主判据）**：沿链路比较**主体误差**与**主体余弦**：
- 若 `val_2591`（打分）主体余弦仍 > 0.9 而 `val_2592`（Softmax 输出）
  主体余弦 < 0.7 ⇒ **Softmax 是引入点**，H-attn 成立。
- 若 `val_2591` 主体余弦已 < 0.7 ⇒ **引入点在打分 MatMul 或更上游**，
  而非 Softmax；须继续上溯 Q/K。
- 若 `val_2591`/`val_2592` 余弦都 > 0.9 而输出 `scaled_dot_product_attention_18`
  余弦骤降 ⇒ **引入点是加权 MatMul（Softmax x V）**。
- 若全链余弦都 > 0.9 ⇒ 注意力段不是引入点，H-attn 被否定，转 #19。

**判据 2（操作化自检，按约束 8）**：本方案的判据依赖"沿依赖链比较"，
该操作化已在第二轮验证过（`trace_dag.py` 读出的真实 DAG，非 Id 顺序）——
执行前须再次确认 `val_2591`/`val_2592` 在 DAG 上确实位于 Q/K 与输出之间。

**判据 3（度量自检）**：若某张量前 1% 元素占能量 > 50%，
**其全量相对 L2 一律不得用于结论**，只用主体口径与余弦。

## 4. 成功 / 失败判断

- **成功**：给出注意力段内**第一个**主体余弦骤降的算子，或明确否定 H-attn。
- **失败·执行方法错误**：设备内存不足（4 GB 中间张量）/ 张量名不存在。
  ⇒ 改为分两次各取一个张量；判据不变。
- **失败·方向错误**：`scaled_dot_product_attention_18` 与已有数据不一致
  ⇒ 两次运行不等价，本次无效。
